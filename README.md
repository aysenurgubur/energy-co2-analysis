# Energy CO₂ Calculator & Analysis

## Project Overview

This project develops an interactive web based tool for estimating CO₂ emissions associated with energy consumption.

Users can select an energy source, enter their energy consumption, and receive an approximate CO₂ emissions estimate based on published emission factors.

The project also includes an analysis of real electricity generation data to compare different energy sources and their associated emissions.

## Main Features

- Interactive CO₂ emissions calculator
- Energy-source selection
- Unit conversion
- Source-specific CO₂ emission factors
- Comparison of different energy sources
- Data analysis using Python
- Visualization of energy production and emissions
- Interactive web interface

## Research Question

How can energy consumption data be converted into understandable estimates of associated CO₂ emissions, and how do these emissions differ between energy sources?
